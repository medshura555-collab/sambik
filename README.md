Python_LR1

Лабораторная работа по обработке и анализу данных с использованием Python.

Требования

- Python 3.12.10
- Git
- Visual Studio Code

Структура проекта

- "data/raw/" — исходные данные, которые не изменяются.
- "data/interim/" — промежуточные данные и отладочные срезы.
- "data/processed/" — обработанные данные.
- "notebooks/" — Jupyter-блокноты.
- "src/" — исходный код проекта.
- "docs/" — документация и материалы отчёта.

Подготовка окружения

Создание виртуального окружения:

py -3.12 -m venv .venv

Активация в Windows PowerShell:

.\.venv\Scripts\Activate.ps1

Назначение проекта

Изучение чтения, очистки, сериализации, оптимизации и анализа данных, а также сравнение библиотек pandas и polars и систем SQLite и PostgreSQL.
