Паспорт среза датасета
1. Общая информация
- Название: NYC Taxi Fare Prediction.
- Источник: Kaggle, соревнование New York City Taxi Fare Prediction.
- Исходный файл: "data/raw/source.csv".
- Размер исходного файла: 5,31 ГБ.
- Формат исходных данных: CSV.
- Формат рабочего среза: Parquet.
- Размер среза: 200 000 строк и 8 столбцов.
- Файл рабочего среза: "data/interim/source.parquet".
2. Описание столбцов
Столбец| Значение| Тип| Пригодность для анализа
"key"| Идентификатор записи| Строка| Для идентификации записей
"fare_amount"| Стоимость поездки| Число с плавающей точкой| Для анализа стоимости
"pickup_datetime"| Дата и время посадки| Строка| Для анализа поездок по времени; нужно преобразовать в дату
"pickup_longitude"| Долгота места посадки| Число с плавающей точкой| Для географического анализа
"pickup_latitude"| Широта места посадки| Число с плавающей точкой| Для географического анализа
"dropoff_longitude"| Долгота места высадки| Число с плавающей точкой| Для географического анализа
"dropoff_latitude"| Широта места высадки| Число с плавающей точкой| Для географического анализа
"passenger_count"| Количество пассажиров| Целое число| Для анализа поездок по числу пассажиров
3. Обнаруженные дефекты
а) В столбцах "dropoff_longitude" и "dropoff_latitude" обнаружено по одному пропущенному значению.
б) Столбец "pickup_datetime" хранится как строка и требует преобразования в формат даты и времени.
в) Необходимо проверить корректность координат, стоимости поездки и количества пассажиров.
г) Следует проверить наличие нереалистичных значений и дубликатов.
4. Вывод
Датасет содержит информацию о поездках на такси в Нью-Йорке. Он подходит для анализа стоимости поездок, времени, координат посадки и высадки, а также количества пассажиров. Выявленные дефекты будут учтены при дальнейшей очистке данных.
